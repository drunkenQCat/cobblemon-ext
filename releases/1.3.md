# Cobblemon Ext 1.3

[简体中文](https://github.com/drunkenQCat/cobblemon-ext/blob/main/releases/1.3.zh-CN.md)

- Adds the ExtHandlers registry: declarative filtered subscriptions, one-shot subscriptions, revocable registration handles and `unregisterAll()`, with filter/action exceptions isolated and logged.
- Registry lifecycle is covered by headless JUnit tests (run through JavaExec's ConsoleLauncher, safe on build paths containing non-ASCII characters).
- No gameplay changes; Poopy Cobblemon 1.2-Fix2 requires this version or later.

Install `cobblemon-ext-1.3.jar` on client and server alongside Cobblemon 1.7.3 NeoForge and Kotlin for Forge. Tested with Minecraft 1.21.1, NeoForge 21.1.240, Java 21. The library does not require Poopy Cobblemon.
