# Cobblemon Ext 1.2

[简体中文](https://github.com/drunkenQCat/cobblemon-ext/blob/main/releases/1.2.zh-CN.md)

- Battle lifecycle events, including turn, active-slot and battle-end notifications.
- Showdown damage and stat-stage bridge with correct private/public HP messages.
- Standalone repository, build and release workflow. Java package: `com.poopycobblemon.cobblemonext`.

Install `cobblemon-ext-1.2.jar` on client and server with Cobblemon 1.7.3 NeoForge and Kotlin for Forge. Tested on Minecraft 1.21.1, NeoForge 21.1.240 and Java 21. Poopy Cobblemon is not required to use this library.
